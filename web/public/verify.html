Independent verifier

Verify outcome

On-chain proof of who won starts with a transaction signature. The verifier reconstructs committed W3O1 rules from public chain data and replays the same selection.

Step 1 · Inputs

Replay any signature

Anyone can run this. The verifier replays from public RPC data and returns a specific reason code.
Raw output

      


      
      

        

           Reason codes
          
What each result means

        

        

          

            
MATCH

            
Replay reproduces the recorded outcome: same rules, same randomness, same winners in the same order.

          

          

            
ERR_TX_NOT_FOUND_OR_NO_LOGS

            
The RPC could not return the transaction or its logs. A fresh transaction can take a few seconds to appear; retry.

          

          

            
ERR_EVENT_NOT_FOUND_FOR_PROGRAM

            
No resolution event from this program in the transaction. Check that it is the draw transaction and the program ID is right.

          

          

            
ERR_ARTIFACT_HASH_MISMATCH

            
The committed rules on-chain do not hash to the value recorded with the result.

          

          

            
ERR_RANDOMNESS_MISMATCH

            
The randomness in the event, the resolution account and the recomputation do not agree. Treat the outcome as invalid.

          

          

            
ERR_REPLAY_UNHANDLED

            
The verifier hit an unexpected error or an unsupported artifact. On public devnet RPC this can be a temporary rate limit; retry.
